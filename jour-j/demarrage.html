Votre démarrage en six étapes

Une dizaine de minutes. Cochez au fur et à mesure : vos cases restent sur cet appareil.

0 sur 6

D'abord, votre squad

L'animation vous répartit dès 12 h 30. Choisissez celle qu'on vous annonce.

  1. Connectez-vous à GitHub dans ce navigateur

    Le Codespace ne s'ouvre que si vous êtes connecté·e avec le compte GitHub que vous avez envoyé au support.

    Ouvrir GitHub

  2. Ouvrez le Codespace de votre squad

    Ne changez aucun réglage : cliquez sur le bouton vert Create codespace. Si GitHub demande l'accès au contexte partagé, choisissez Authorize and continue. Si l'éditeur demande de faire confiance au dossier, choisissez Approuver le dossier et continuer.

    Choisissez d'abord votre squad

  3. Attendez le message « ✓ Codespace prêt »

    Le terminal installe les outils en bas de l'écran : quelques minutes. Ne tapez rien avant ce message. Si vous fermez l'onglet, retrouvez votre Codespace sur github.com/codespaces : ne recliquez pas le lien de votre squad, cela en créerait un deuxième.

  4. Connectez Claude avec le compte fourni

    Dans le terminal, tapez :

    claude auth login

    Une fenêtre propose d'ouvrir un lien : cliquez sur Ouvrir, connectez-vous avec les identifiants remis lundi par l'équipe Programme AI4D, puis autorisez. La page affiche ensuite un code : copiez-le, revenez dans le terminal (il attend « Paste code here »), collez-le et appuyez sur Entrée.

    Pour vérifier que c'est bon, tapez :

    claude auth status --text

    Il doit afficher votre compte. S'il répond « Not logged in », le code n'a pas encore été collé.

  5. Ouvrez Claude et laissez-le vous accueillir

    Dans la barre verticale tout à gauche du Codespace, cliquez sur la petite icône Claude (une étoile), puis sur Nouvelle session (New session). Un panneau Claude s'ouvre à côté de l'éditeur. Dans sa zone de saisie, en bas, tapez :

    /bienvenue

    L'accueil vérifie votre environnement et vous donne votre premier pas. Quand vous tapez /, un menu liste les commandes, dont /bienvenue et /coach. Votre consommation apparaît dans la barre de gauche, sous « Session ». Ignorez le panneau « Créer avec des assistants » à droite : ce n'est pas Claude.

    Vous préférez le terminal ? Tapez claude. Au premier lancement, il pose quelques questions (style de texte, notes de sécurité, confiance du dossier) : répondez par Entrée, et Oui à la confiance du dossier.

  6. Laissez-vous guider : la phrase « À vous », puis /coach

    L'accueil se termine par une phrase à taper dans Claude : c'est votre première action. Ensuite, à chaque fois que vous vous demandez quoi faire, tapez /coach : il dit où vous en êtes et la prochaine phrase à taper.

    L'écran de votre squad (avancement, prochaine étape, gates, contrats de toutes les squads) : une notification « port 4000 » propose de l'ouvrir. Sinon, onglet Ports en bas du Codespace, ligne 4000, icône globe.

Besoin d'aide ? Vous pouvez faire appel au support de l'équipe Programme AI4D.

Si quelque chose ne va pas

Le terminal est resté vide, ou le dossier context-nexus n'apparaît pas

Vous avez peut-être rouvert un ancien Codespace. Supprimez-le sur github.com/codespaces, puis recréez-le depuis le lien de votre squad (étape 2).

« claude » : commande introuvable

Le Codespace n'a pas fini son installation. Attendez « ✓ Codespace prêt », puis ouvrez un nouveau terminal.

« Not logged in » alors que j'ai autorisé la connexion

Le terminal où tourne claude auth login attend encore le code que la page de Claude affiche : collez-le dans ce terminal, puis Entrée. Si la page a expiré : Ctrl + C, puis relancez claude auth login.

Claude demande de se connecter, ou refuse

Relancez claude auth login. Toujours bloqué : faites appel au support de l'équipe Programme AI4D.

L'agent ne semble pas connaître mon volet, ou la commande /bienvenue n'existe pas

Tapez npm run context, relancez claude, puis /bienvenue. Le résumé doit citer votre volet et les contrats des autres squads.
